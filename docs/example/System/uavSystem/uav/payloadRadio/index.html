payloadRadio ()

System::uavSystem::uav::payloadRadio

Technical data

frequency

5800 MHz

data rate

250000 B/s

encrypted

true

The payload radio sends the payload’s data to the ground over the data antenna, sits on the CAN bus and draws power from the BEC.

Properties

mass

0.6 kg

power

8 W

Members

Interfaces

  • payloadRfLink -> dataAntenna

  • payloadDataLink -> payload

  • canBusLink -> flightController, imu, gps, motorController

  • payloadRadioPower -> bec
