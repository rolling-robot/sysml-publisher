canBus ()

System::uavSystem::uav::canBus

Technical data

bit rate

125000 B/s

nodes

5

terminated

true

The CAN bus: the shared digital link between the flight controller, the IMU, the GPS, the payload radio and the motor controller.

Properties

mass

0.2 kg

power

0.5 W
